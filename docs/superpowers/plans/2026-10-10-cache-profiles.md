# 缓存组配置实施计划

**目标：** 根据本机 dingo-cache -hh 完整展示参数说明和默认值，支持共享模板及创建时一次性修改。
**架构：** 独立 cache_profiles 模块提供版本化 CRUD 和参数目录；创建/端口规划保存不可变参数快照，成员基础配置覆盖模板中的成员默认值。现有权限、幂等、端口预留和进程管理机制保留。
**技术：** FastAPI、SQLAlchemy/Alembic、React/TypeScript。

用户已授权自主设计并实现，不再进行中途确认；在当前工作区保留已有修改，不提交或部署真实服务。

- [x] 参数目录与严格校验：保存帮助原文及版本；覆盖所有参数，平台托管字段只读；类型、范围、未知参数验证测试。
- [x] 模板持久化：新增迁移和模型、CRUD、权限、软删除、修订冲突；测试普通用户/管理员权限及失效配置。
- [x] 创建流程：模板默认值/本次参数/成员覆盖次序明确；规划快照及实际 argv 保留参数，防止覆盖身份；测试构建和快照。
- [x] 前端：独立菜单、模板列表/编辑、分组搜索参数及默认值；创建选择/本次编辑/刷新；不修改模板原件。
- [x] 验证：隔离数据库后端定向测试、前端测试、类型构建、模拟浏览器创建链路、迁移；补充部署说明。不连接或操作真实缓存集群。

平台托管：id/group_name/listen_ip/listen_port/mds_addrs/log_dir/daemonize/conf/cache_dir_uuid。
成员默认值：cache_dir/cache_size_mb/use_rdma/cache_rdma_device/cache_rdma_port_num；成员表单最终值优先，新增成员继承当前模板的这些默认值。
其他可编辑参数：按 -hh 的准确名称、类型和说明保存；未显式配置不强制发送二进制默认值。cache_expire_s 仅在用户显式配置时传入 argv；未配置时保留旧版本兼容行为。

验收记录：94 参数与帮助原文一致；隔离 PostgreSQL 中验证 CRUD 权限、模板失效及不可变创建快照；前端配置到端口规划自动创建的浏览器流程通过。修正了参数表隐藏标签导致的额外页面高度，并加入高度断言。实际缓存集群未连接、未启动、未停止。
