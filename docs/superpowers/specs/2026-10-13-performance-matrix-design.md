# 性能测试参数组合

目的：一次任务覆盖 fio / elbencho 的多组参数，逐场景执行、查看进度和报告。用户授权自行设计、实现、测试和部署。

- 每个工具独立配置；Direct I/O、并发、文件大小/总大小、文件数、块大小、读写模式、轮次、队列深度、混合读比例支持多个候选值。
- 大小仍按“每文件大小×数量”或“总量÷数量”二选一。参数取笛卡尔积；读比例只在混合读写组合中展开。
- 服务端统一展开、规范化、去重、校验。任一非法组合拒绝整份计划并给出具体参数原因；最多256个候选组合，禁止不知情地跳过组合。
- 预览列出每个场景参数、命令、场景数和保留数据总量。编辑后旧预览失效；任务超时覆盖整批任务。
- 场景编号稳定；每场景独立数据/输出目录。工具普通失败继续后续场景，最终任务为失败。超时、取消、挂载丢失、启动异常停止后续场景；保留已完成报告，未执行明确标记。
- 每个场景按自己的轮次取均值，不把不同参数性能混合平均。报告表支持查看各场景网页报告及附件；旧任务报告仍可打开。
- 执行状态传输与报告正文分离；实时收集轻量场景状态，结束再收集有界附件。最多32MiB序列化附件，原始报告全部保留远端。
- 不改 dtt 命令契约，不另起调度服务、不迁移数据库；复用现有 supervisor 和 JSON 字段。
