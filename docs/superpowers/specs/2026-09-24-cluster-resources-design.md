# 集群文件系统、缓存组与挂载点管理

## 目标与权限
集群详情提供三个管理区。所有登录用户可查看平台记录，管理员可操作全部，普通用户只能操作自己创建的集群；操作额外机器时同时要求拥有该机器。命令始终使用集群的真实名称、采集到的 MDS 地址和登记的执行用户，别名不参与执行。

## 文件系统
提供列表/详情、S3/RADOS 创建、删除，文件系统配额与目录配额的设置/查询/清除；回收站配置查询、保留天数修改与恢复；目录统计 info/summary、开启关闭、同步和修复。严格参考 integration-test/template/dingofs_command.py。S3/RADOS 密钥只在任务等待执行或 sudo 认证期间加密保存，终态清除；输出、审计和公共参数脱敏。

## 缓存组
缓存组由成员加入形成，没有单独 group create/delete 命令。创建允许选择多台已登记且有权限的机器，每项填写成员监听端口、目录、容量、RDMA 参数。平台生成成员 UUID 和专属目录，记录各成员进程身份。停止先 leave 再验证进程身份后发送 SIGTERM；删除等待离线并逐个删除成员元数据，不删除缓存目录。组停止/删除作用于平台创建的全部成员；外部缓存组可查询，因缺少可信进程归属记录不直接接管。部分成功和超时明确显示，不误报成功。

## 挂载点
选择有权限的机器、执行用户、文件系统和绝对目录，可设子目录、缓存组、RDMA。挂载前检查冲突，拒绝覆盖已有挂载。平台生成专属日志目录并记录操作结果；卸载只作用于登记的挂载，读取客户端日志只接受该记录对应的日志目录和普通文件名，提供文件列表及有限行数尾部读取。

## 异步执行与记录
独立 resource_operations 和 managed_resources 表。请求使用客户端 UUID 去重，所有写操作需前端确认及后端 confirmed=true；资源参数由服务端验证，命令由固定 helper 生成，不接收任意 shell。任务保留步骤结果、游标和目标机器版本，逐步执行；sudo 密码只在当次执行使用，认证恢复不重复已完成步骤。取消/超时明确为结果可能未知；每次操作重新验证账号会话、资源权限和版本，集群操作互斥。

## 验证边界
使用本机临时 PostgreSQL、mock SSH、固定 helper 单元测试与前端测试，验证错误输出、权限、去重、密钥脱敏、部分成功、取消和认证恢复。不在真实集群创建、删除、挂载或停止资源。部署需数据库迁移并重建 API/Web。
