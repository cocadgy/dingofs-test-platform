# MLPerf Storage 3.0 引导式测试

用户已确认：DTT 升级到支持 KV Cache 的 MLPerf Storage 3.0 系列，并在平台引导式性能测试中接入训练、Checkpoint、KV Cache。

## 方案

采用单一、固定版本的 3.0.x 及其匹配依赖，统一 DTT 和平台接口。不同时维护两套运行环境，也不只替换镜像依赖而保留旧命令。具体 tag、commit 和依赖须经上游源码核验后记录；不跟随 main 漂移。

## 行为

- 复用目标集群、机器、挂载、任务状态、日志及报告入口。
- 训练保留已有模型和参数意图，按固定版本支持的模式适配；不静默换模型。
- Checkpoint 提供模型、写/读/写后读、次数与并发；展示预计数据量。读取必须使用兼容的检查点输入，不能对空目录假装读取成功。
- KV Cache 提供模型、时长、并发及存储容量配置，缓存层与详细负载参数折叠；参数语义遵循选定版本，容量与实际写入量不混淆。
- 新任务记录引擎版本、场景、有效参数、原始结果和场景指标；自定义运行标识为内部测试，不声称官方合规。
- 保留旧报告读取；旧 DTT 不支持新场景时明确提示升级。

## 验证与范围

覆盖参数校验、实际 argv、错误传播、报告身份与指标、引导交互及现有训练回归。使用本地临时目录做小规模运行，不占用异常的 129 集群。部署、推送和真实集群压测不隐含在代码完成声明中。
