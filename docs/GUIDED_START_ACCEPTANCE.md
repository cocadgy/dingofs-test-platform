# 开始页面：添加机器与集群验收

登录后，在左侧“开始”选择“添加机器”，点击“下一步”。填写机器名称、地址、SSH 端口（默认 22）、SSH 用户和 SSH 密码，然后点击“检查连接并添加”。当前仅支持 SSH 密码认证；连接时沿用平台的自动信任主机密钥策略。

平台先验证 SSH 并采集硬件信息，再保存机器。SSH 认证、连接或全部硬件采集失败时，不会创建机器。部分硬件信息可用时允许创建，结果页会提示信息不完整，未知字段显示“未知”。密码不会写入 URL 或浏览器存储；离开表单和会话失效时表单卸载，密码状态随之清除。

成功页显示机器名称、SSH 地址、逻辑 CPU 核数、内存、物理磁盘数量、RDMA 状态和最近成功采集时间，并提供机器详情链接。从添加集群流程中先添加机器时，成功后可点“继续添加集群”，返回并自动选中新机器；直接添加机器时仍可返回开始页。

验收时使用已授权且未登记的临时 SSH 目标：先用错误密码提交，确认机器数量不变；再用正确密码提交，确认恰好新增一台机器，并核对硬件摘要。完成后通过平台正常归档这台临时机器，不要删除已有资源。

## 添加已有集群

在“开始”选择“添加集群”。第一步选择已登记的执行机器，执行用户默认带出机器的 SSH 用户，可按实际情况修改；没有目标机器时点击“先添加机器”，完成后返回此页，机器列表会刷新并选中新机器。第二步点击“查询集群”，在发现结果中勾选要登记的集群。第三步核对执行机器、执行用户和集群名称，点击“确认添加”。成功后提供集群详情链接。

此流程只登记远端已有集群，不会创建远端集群。`dingo` 路径和配置目录由现有发现流程获取。需要临时用户切换认证时显示一次性密码输入；若已有登记的管理入口不同，不会自动覆盖，必须按原有流程确认绑定。其他引导任务仍显示“即将支持”。
