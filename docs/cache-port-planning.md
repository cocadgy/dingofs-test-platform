缓存端口规划实现步骤
1. 增加 cache.plan 只读远端任务，自动/手动端口模式，默认前端自动；旧接口省略模式保持手动兼容。
2. 规划生成固定 UUID 与目录。检查实际 TCP bind、MDS 登记、平台进行中预留；规划结果持久化，10 分钟内仅创建者可确认一次。
3. cache.create(plan_id) 复用规划记录并重新验证权限/版本；远端启动前重检并持久化实际端口；恢复和停止使用持久端口。
4. 表单展示检查清单及最终确认，修改输入使旧清单失效。手动冲突显示原因和建议端口。
5. 定向测试规划/过期/重放/认证/并发预留、实际 socket 冲突、前端确认与结果显示，不启动真实缓存集群。

最新交互：点击“检查并创建缓存组”即授权检查成功后自动创建，取消二次点击和确认框。失败不启动；停止、删除仍需确认。
