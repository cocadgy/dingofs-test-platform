# 机器概览表格验收

## 实现范围

- 全宽概览表格，每行一台机器，10 列按用户要求排列。
- 每列独立搜索、升降序排序；组合条件同时生效；全部记录先筛选排序再分页。
- 最大网卡速率、物理磁盘容量、RDMA 去重、快照更新时间明确计算。
- 独立机器详情 URL，支持刷新、浏览器返回、概览返回时保留搜索/排序/页码。
- 保留原机器编辑、采集、归档、SSH 指纹确认及权限控制。
- 离开未保存表单时提示；离开模块后较晚完成的创建请求不会改变当前页面。

## 验证

后端验证字段投影、容量计算、最大网卡速率、缺失信息、部分结果时间、分页权限和过期采集状态。前端验证全部 10 列的搜索排序、数字排序、未知值置后、跨数据页搜索、数据加载失败、详情路由和未保存表单保护。

浏览器在隔离站点使用 45 台模拟机器，验证跨页搜索、多列筛选、更新时间列点击进入详情、详情刷新、浏览器返回、返回时筛选和页码保留，并运行原硬件采集、SSH 信任、配置管理和用户管理流程。没有连接真实机器或重启正在使用的网站。

验证结果：后端 77 项通过（Python 3.12 容器），前端 20 项通过，浏览器 6 条流程通过，TypeScript/Vite 和 Docker 构建通过。

## 手工操作

更新服务后打开“机器资源”：

1. 在各列表头搜索框输入条件，例如资源名、CPU 型号、内存 `64`、RDMA `mlx5`。
2. 点击列标题，检查升序、降序和未知值置后。
3. 翻页后修改搜索条件，确认能找到其他页的机器，且回到筛选后的第一页。
4. 点击机器行或更新时间单元格进入详情，执行已有操作后返回概览。
5. 确认筛选、排序和页码保留；详情 URL 刷新后仍显示同一机器。
