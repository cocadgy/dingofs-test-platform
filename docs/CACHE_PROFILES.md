# 缓存组配置

## 使用流程

1. 在左侧“缓存组配置”中点击“新建缓存组配置”，填写名称和说明。
2. 按参数分类或搜索参数名/说明查找设置。每项显示准确的 CLI 名称、类型、帮助说明和默认值。勾选“自定义”后填写值；取消勾选表示不传入该选项，而不是把默认值写死。
3. 保存后，在集群的“资源管理 → 缓存组 → 创建缓存组”中选择配置。
4. 展开“查看 / 修改本次启动参数”修改本次使用的参数；在成员表单中选择机器、执行用户、监听地址、缓存基础目录、容量及 RDMA 设置。新增成员继承模板中的成员默认值。
5. 点击“检查并创建缓存组”。平台检查端口，通过后自动创建，沿用密码认证、命令输出、启动日志与实际缓存组列表刷新流程。

本次修改不会回写模板。更换模板会重新应用容量和 RDMA 默认值；模板指定缓存基础目录时也会应用该目录。不使用模板时也能自定义启动参数。

## 参数来源与覆盖规则

目录来源：本机 `~/.dingo/components/dingo-cache/latest/dingo-cache -hh`，版本 `main-fe4384a0b`，共 94 项。帮助原文保存在 [reference/dingo-cache-main-fe4384a0b-help.txt](reference/dingo-cache-main-fe4384a0b-help.txt)。未声明默认值的参数显示“帮助未声明”。目标机器程序版本不同可能不支持某些选项，启动失败原因会保留在现有命令结果及进程日志中。

- 模板保存显式设置，不把所有二进制默认值强制传入启动命令。
- 创建页面提交当前完整参数副本；取消某个自定义设置会从本次副本删除该参数，不会再次从模板合并回来。
- 容量、基础目录和 RDMA 参数为成员默认值。每个成员表单里的最终值优先。平台容量初始值为 1024 MiB；帮助中的二进制默认值为 102400 MiB，两者在界面中分别说明。
- 每个成员使用独立 UUID 子目录。帮助声明的多目录语法暂不开放，沿用平台现有单基础目录管理。
- UUID、组名、监听地址/端口、MDS、日志目录、后台启动、外部配置文件和内部目录 UUID 由平台管理；目录中保留说明，只读展示。不得用模板绕过端口检查或改变进程归属。
- 参数经过服务端白名单、类型、数值范围和控制字符校验，以 argv 传递，不拼接可执行 shell 文本。
- 参数检查完成后的创建计划保存不可变快照。模板之后更新、停用或删除，不修改已规划或运行的成员。
- 新提交的计划若引用已更新/停用/删除的模板会拒绝，用户刷新后重新选择。

## 权限

登录用户可查看、选择和复制所有配置，也可新建配置；普通用户只能修改、启停或删除自己创建的模板，管理员可管理全部模板。停用仅阻止新建计划选择，不停止缓存进程；删除为软删除，不删除缓存数据。
