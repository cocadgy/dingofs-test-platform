# 机器 SSH 密码与硬件采集验收

实现范围：机器 SSH 密码配置、Linux 硬件只读采集、管理员手动更新、普通用户查看。

## 已实现行为

- 添加/编辑机器时可录入 SSH 密码，密码加密保存；接口只返回“是否已配置”，不返回明文或密文。编辑留空保留，勾选清除才删除。
- “更新机器信息”使用该机器的地址、端口、SSH 用户和密码；校验数据库中管理员确认的公钥；首次连接通过页面确认指纹，不使用意外的本地 SSH agent 或密钥。
- 展示 CPU 型号及核数、内存、磁盘设备、挂载文件系统容量、网卡 IP/MAC/状态/速率/MTU、RDMA 设备与端口映射。
- 物理磁盘容量与分区、LVM、挂载点分开统计。不可获取的物理核数/速率显示未知。
- 显示采集状态、最近尝试和最近完整成功时间；部分结果单独展示；失败不丢弃上次完整结果。
- 30 秒控制器总超时覆盖 DNS、SSH 认证和远端命令；输出有上限，SSH 连接和子进程均清理。
- 同一机器禁止重复采集，过期任务可重试；配置修改、归档或权限撤销时旧结果不提交。
- 数据库升级保留原机器和管理上下文关联。

## 验证结果

- Python 3.12 部署镜像：后端 72 项测试通过（5 条既有依赖弃用警告）。
- 前端组件：14 项通过。
- 浏览器流程：5 条通过。
- TypeScript、生产构建、API 镜像构建、Compose 配置和 diff 检查通过。

## 验证方式

后端：隔离 PostgreSQL，覆盖密码保护、资源回归、SSH 截止时间、主机身份错误、真实 loopback SSH 协议、硬件解析、刷新并发与权限、旧账号和机器升级。

前端：组件测试覆盖普通用户只读、刷新期间禁用、失败保留信息、部分结果以及容量格式；TypeScript 检查与生产构建。

浏览器：临时前后端与隔离数据库，SSH 输出使用测试替身；验证创建密码、留空编辑保留、刷新完整快照、失败仍保留、普通用户只读、清除密码，同时运行原资源/YAML和用户管理流程。

没有连接真实服务器、执行集群操作或重启现有网站。真实机器的网络、工具可用性和采集数据需部署后手工验收。

## 手工验收

1. 按 `DEVELOPMENT.md` 的“机器 SSH 密码和硬件采集”配置持久加密密钥，重新构建启动服务。
2. 管理员登记或编辑一台 Linux 机器，输入对应 SSH 用户的密码并保存；详情仅显示已配置。
3. 再编辑机器，确认密码不回填，留空保存后依然已配置。
4. 点击更新机器信息，首次显示 SSH 指纹；管理员核对后勾选确认，点击“信任并继续”，随后显示硬件结果及更新时间。
5. 检查 CPU、内存、物理盘与分区、挂载点、网卡/RDMA 明细是否与机器一致。
6. 输入错误密码后采集，确认认证错误可见、旧完整数据仍保留；恢复正确密码。
7. 普通用户登录只可查看，不显示更新或密码编辑入口。
8. 清除密码后再刷新，应提示先配置 SSH 密码。

## 网页主机信任补充验收

- 不存在 known_hosts 的新机器可以展示指纹，确认前不能发送密码。
- 用户未勾选核对时，信任按钮禁用；普通用户无确认入口。
- 确认后信任记录保存在数据库，刷新/重新登录无需重复确认。
- 主机密钥变化时展示原指纹和新指纹，不发送密码、不覆盖上次硬件信息。
- 过期、重复、被编辑的机器配置和非管理员的确认请求均拒绝。
