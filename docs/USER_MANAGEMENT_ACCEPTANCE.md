# 用户管理增量验收

2026-09-23，在第一阶段基础上增加用户管理及个人设置。

## 实现

- 管理员 API：GET/POST `/api/v1/users`，PATCH/DELETE `/api/v1/users/{id}`，POST `/api/v1/users/{id}/reset-password`。
- 用户 API：PATCH `/api/v1/auth/profile`；修改邮箱和密码均验证 current_password。
- 用户数据增加 email；新账号强制填写，旧账号允许待补填并在登录后提示，不伪造邮箱。
- 管理写操作要求管理员权限、CSRF、base_revision。用户管理和登录使用同一数据库事务锁，串行处理撤销会话与创建会话，避免禁用或重置后的旧登录重新生效。
- 最后一个启用管理员不能被禁用或删除；并发测试验证该约束。
- 禁用、删除、重置及改密撤销相关会话，审计只记录字段名和操作，不记录密码。
- 新建及自行修改密码沿用至少 6 位；管理员重置按需求固定为 123456。
